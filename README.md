# 来物 Italia · 米兰与深圳的初次相遇

帮助意大利原产商品准备中文展示、完成范围确认，并记录深圳消费者的具体反馈。**当前版本 0.3.0：开心果酱、意大利巧克力、意大利香水、意大利咖啡。成人纺织配饰共创暂停。**

米兰是品牌接洽入口，深圳是测试城市；商品品牌、具体地区与实际制造地分别记录。品牌合作与需求仍待验证，参考照片不代表已经取得品牌授权。

## 立即运行

需要 Node.js 22.9 以上；没有第三方运行依赖，不需要安装依赖或模型密钥。

```powershell
node server/index.mjs
```

打开 [本机演示](http://127.0.0.1:3100/#discover)。默认 Mock 模式使用本地模板，服务只监听 `127.0.0.1`。

```powershell
# 可选：读取本机模型配置
node --env-file-if-exists=.env server/index.mjs

# 后端与 HTTP 集成验证
node --test tests/*.test.mjs

# 浏览器验证：先启动服务，另需可用的 Playwright + Chromium
# 可设置 PLAYWRIGHT_PATH 指向本机 playwright 模块目录
node scripts/verify-italia-ui.cjs
```

## 本轮可以体验

1. 四类商品参考实拍、意大利专用首页与展示策划。
2. 五步准备：文化整理 → 展示策划 → 商品资料核对 → 真人叙事 → 发布前检查。每步记录真实开始、完成和耗时；模板模式默认每步至少 2 秒，含阅读停留，总计约 10 秒。
3. 品牌、文化与译审、真人主播、展示确认、体验观众五种视角。品牌档案和复盘支持中英文界面，保留意大利语原文。
4. 商品档案、来源依据、素材范围、人工译审、品牌与主播确认；资料变更会撤销当前版确认。
5. 按版本、用途、渠道和期限确认展示，保存完整快照；退回、撤回、到期或问题记录会阻止相应内容继续展示。
6. 本地真人舞台、可选本机镜头、人工触发角色特效、独立停止按钮。已打开的舞台及观众页每 3 秒核对展示状态，页面重新获得焦点时也会检查。
7. 按包装与设计、故事理解、感官与使用体验、价格接受度整理反馈；每条保留场次、版本和体验方式，区分看图期待与自述实物体验。
8. 品牌记录继续、修改或暂停的理由，导出含档案、确认、版本、问题与反馈的 Markdown 测试资料包。

意大利试点不生成中国生产成本、MOQ 或交期；生产询价和打样入口在服务端也已限制。历史文化共创代码及本机资料保留，旧流程不再作为新建项目入口。

## 运行边界

这是免密钥本机原型。角色切换是流程演示，未实现真实登录、组织权限或账号数据隔离。资料完整检查与人工确认记录不等于商品真实性鉴定、法律授权或进口许可。

目前没有真实订单、支付、进口办理、外部直播、自动消费者采集或数字人识别。镜头仅本地预览，文字挑战不能证明真人身份。实际授权、商品标签及体验安排需真实项目另行落实；本轮没有实际品牌付费或需求验证结果。

数据写入 `.local/projects.json`，已加入 Git 忽略规则。浏览器保存最近项目 ID。每个项目最多 100 次文案修订、200 条反馈、500 次业务操作，总计最多 50 个项目；超限会提示，不会自动删除旧记录。保存的是项目内版本与人工记录，没有跨品牌自动学习。

## 可选模型接口

复制 `.env.example` 为 `.env`，只在本机填写服务商配置：

```dotenv
AI_PROVIDER=openai-compatible
AI_BASE_URL=https://你的服务商/相容接口根路径
AI_MODEL=账户可用模型名
AI_API_KEY=仅保存在本机
AI_RESPONSE_FORMAT=json_schema
AI_TOKEN_PARAMETER=max_completion_tokens
```

服务端调用 `AI_BASE_URL + /chat/completions`，密钥不进入前端。每次生成有三个模型节点：文化整理、展示策划、双语稿；商品资料检查与展示放行使用确定性规则和人工确认。输出先校验结构，失败保留错误，不悄悄回退为模板结果。真实模型网络尚未验收。
