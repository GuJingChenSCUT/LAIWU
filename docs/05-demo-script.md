# 三分钟分角色演示讲稿

版本 0.2.0。建议提前生成摩洛哥帆布袋提案，在五种角色之间切换；展示时始终保留「免密钥演示」和本机预览提示。询价、样品和人物均为演示资料。

## 0:00–0:25 让普通人的文化经验有一件作品

「这是一位虚构创作者对家乡纹样的个人记忆。我们把故事、创作者和制造能力放到一张桌子上，让品牌在进入中国市场之前，先完成一次可复盘的小实验。」

操作：灵感集市 → 摩洛哥帆布袋示例 → 共创设计。时间紧时使用预先生成的提案。

## 0:25–1:05 让每个人知道下一步

「文化方负责来源和使用范围，品牌决定展示什么，供应商回答如何制作，主播把故事讲给人听。每一棒都有交付物。」

操作：合作工作台 → 展示品牌待办 → 切换文化创作者，展示署名、依据、范围和文化签收 → 品牌确认展示范围。

「展示确认不意味着可以量产，也不触发采购或付款。当前是角色流程演练，还没有真实账号。」

## 1:05–1:35 把询价落到具体字段

「我们把帆布袋写成一份明确的规格：尺寸、公差、面料、印花、数量和验收要求。供应商才能回答。」

操作：品牌冻结规格 → 供应商先提交只填单价的回复 → 展示不能算总价的缺项 → 填入完整虚构示例 → 查看同口径金额。样品返工流程可在问答时展开。

「这里的价格是示例。运费未知不会被当成零，报价也不代表拿到了订单。」

## 1:35–2:10 真人表达，AI 帮忙准备

「主播核对中文和英文，文化、品牌、讲稿三方确认齐全，才生成这一次试讲的内容快照。」

操作：主播签收双语稿 → 建立场次 → 进入真人舞台 → 触发角色互动 → 点击停止画面与特效。

「真人负责幽默与即兴，特效为表达服务。停止按钮在本机立即执行，不依赖 AI；当前没有外部推流，也没有真假数字人鉴定器。」

## 2:10–2:40 反馈属于观众看过的那一版

「观众看到的是概念，不会把文化来源误认为生产地，也不会把反馈提交误认为下单。」

操作：观众视角 → 提交“我想摸一摸面料” → 复盘查看反馈 → 品牌记录下一步决定。时间允许时修改中文，展示签收失效与英文重新待核对。

「修改稿子后，旧场次收到的意见仍留在旧版本，不会偷偷贴到新产品上。」

## 2:40–3:00 商业落点

「我们先服务有真实中国市场探索需求的海外文化小品牌，交付一轮概念准备、角色交接和反馈复盘。下一步找真实品牌、文化权利人和供应商，用一件小商品验证是否减少沟通与返工，以及品牌是否愿意付费。」

操作：品牌 → 交付与复盘 → 下载交接包。结束时停在品牌决定和交接日志。

## 评委追问

- 和普通大模型有什么不同？生成之外，有范围、版本、角色交接、询价缺项、样品返工和场次反馈；商业价值还需真实试点验证。
- 有没有真实供应链？现在有可运行的询价和样品演练流程，示例工坊不是真实合作方。
- 能直接开餐厅或进口商品吗？R2–R5 当前只整理资料。餐饮许可、进口、出口需要专业服务和独立验收。
- 为什么先做 R0/R1？三小时内可以把文化共创与真人体验做完整；样品演练作为可选分支。
- 能否直接给供应商上线使用？还需邀请登录、组织权限、数据隔离、真实授权、合同与文件证据。
- 能确认市场会买单吗？还不能。反馈次数不是购买人数、订单或成交率。
