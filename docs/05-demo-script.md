# 来物 Italia · 三分钟演示

版本 0.3.0。四类意大利原产商品的中国市场展示与反馈测试；纺织配饰共创暂停。先准备一个明确标记为演示的项目与资料，不将示例当作实际商品凭证。

## 0:00–0:25 一件原商品，一个具体问题

打开灵感集市。四张团队照片分别对应开心果酱、巧克力、香水和咖啡。

讲述：“我们从可接触的意大利品牌开始，在深圳听到第一轮消费者反馈。米兰是接洽入口；商品的具体地区与制造地单独核对。这次先保留原商品，不开发纺织共创款。”

## 0:25–0:50 展示准备是一个可见过程

选择商品并生成。五步每步默认至少两秒，展示开始、完成和耗时。

讲述：“AI 可以辅助整理故事和准备双语稿。这里是免密钥模板演示；商品事实、展示范围和最终确认由人核对。系统不编造生产报价。”

## 0:50–1:25 让资料对得上表达

打开合作工作台，切换品牌端 English。展示原文、英文说明、中文表述，以及制造地、规格、配料或成分、来源依据。切换文化与译审，展示素材范围和三语核对。

讲述：“照片不等于授权。资料可以先存草稿，但资料缺失时不能开始展示。品牌与主播各自确认当前版本，不能互相代签。”

## 1:25–1:55 确认的是具体版本

打开展示确认，展开送审资料。展示用途、渠道、有效期、四项人工核对及依据，然后建立本机场次。

讲述：“确认会冻结这一版内容。修改后需要重新确认，旧场次的反馈仍然对应它看到的版本。这里是本机流程演示，不是真实身份签名或外部直播发布。”

## 1:55–2:25 真人讲述与观众回应

进入真人舞台，触发一次角色互动，再演示停止。进入观众页，选择反馈主题和体验方式。

讲述：“看过照片、听过故事，与真正尝过或闻过商品，是不同的反馈。我们把包装、故事、感官体验和价格分开记录，不让看图期待变成虚构的实物体验。”

## 2:25–3:00 让反馈影响下一步

品牌方查看四维复盘、录入原话、场次版本与体验方式，保存继续、修改或暂停理由，下载测试资料包。

讲述：“下一步用一个真实品牌、一个商品和一次小规模展示，验证客户是否愿意为这份交付付费。今天展示的是可运行流程，还不是已经成立的需求或订单。”

问答时可展示问题处理：主播记录具体口误 → 内容暂停 → 保存更正依据 → 新版重新确认 → 新场次开放。旧场次不会自动恢复。
