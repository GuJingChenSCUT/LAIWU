## 如何复跑

先启动服务。在已安装 Playwright 的环境运行 `node scripts/verify-business-ui.cjs`；如不在 Node 模块搜索路径，用 `PLAYWRIGHT_PATH` 指向现有模块目录。`scripts/verify-ui.cjs` 为相同检查的兼容入口。

检查会创建一个标记为演示的本机项目、报价、样品记录和观众反馈；这些都不是生产数据。
